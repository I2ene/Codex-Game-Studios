# Genre reference library

Adapted from Donchitos' upstream v1.3.0 genre guidance; see [attribution](../../NOTICE.md).
Read chipsets.yaml to match meanings, then only the relevant sheets. Preserve each
default's reason and Break condition, the user's words, Keep/Avoid and per-system
mashup ownership. These are design hypotheses, not measured balance targets.

Statements about tested or untested routes describe the upstream reference's scope;
they do not record Codex model, engine, device, network or game-quality execution.
Source keys resolve in sources.md; inherited source dates are not fresh verification.
A local stand-in never establishes real network/device support. Explicit user choices
and supported current tooling govern actual work.
