# Error Recovery Protocol

Shared procedure for required professional work performed by the parent or actual
authorized delegates. Orchestration/review skills retain their specific blockers
and the requirements to surface failure immediately and produce a partial report.

## Trigger 0 — verify the artifact before reporting completion

If the return contract names a path, check that it exists before treating the
phase as complete. A named artifact missing from disk is a failed phase, whether
the author is the parent or a delegate. A fluent response is not evidence that
the work ran; inspect required artifacts and execution evidence.

When a required path is missing:
1. Do not advance dependent work or summarize the phase as complete.
2. For parent work, identify the unmet contract and complete it within existing
   authorization, or report the blocker. For a real delegate, prefer resuming
   that participant with the unmet contract over starting a new investigation.
3. If the retry still produces no artifact, treat the phase as BLOCKED and apply
   the recovery procedure below. Never invent participants or completed evidence.

## Recover blocked work

If required parent work or an authorized delegate is BLOCKED, errors or cannot
complete:
1. **Surface immediately** — report the responsible discipline, actual source
   (parent or participant), missing input/artifact and its expected path.
2. **Assess dependencies** — preserve independent completed work, but do not
   proceed past a real dependency until its required input is available or an
   applicable explicit user decision resolves the block.
3. **Offer applicable options** via the host's user-input mechanism:
   - Retry with narrower scope or resolve the missing input.
   - Have the parent apply the required expertise within existing authorization,
     or assign a real authorized delegate using available tools. This is a change
     of execution path, not evidence that the missing work has already completed.
   - Leave the work unperformed, name the gap, or stop to resolve it first.
4. **Always produce a partial report** — retain completed work and actual results.
5. **A skip does not clear a required block.** If required team work remains
   missing, the final verdict is BLOCKED, not COMPLETE. A later parent assessment
   can satisfy the same professional contract only after it is actually performed
   and evidenced. Label it as parent work; never fabricate independent review or
   another person's sign-off. Mode/applicability skips remain distinct from failed
   or unassessed required work.
