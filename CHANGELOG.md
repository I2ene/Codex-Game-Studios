# Changelog

## 2.1.0

Integrates Donchitos' upstream 1.2.0 workflow, including the 1.1.3 changes.
Stage-specific references and the rebuilt story and onboarding paths preserve
professional checks when resuming work. Registry IDs, ADR dependencies, gate
coverage, story file scope and playtest evidence follow the updated contracts.

The native CLI adds explicit observations for Markdown sections, project state,
read and write checks, skill lint and test scaffolding. Optional Bash utilities
reuse upstream data analyses. Configuration inspection reports and merges duplicate
keys; writes and configured command execution require the ambiguity to be repaired.
The owner-tracked installer preserves consumer configuration and context while
replacing or retiring only unedited managed references.

See the [source map and compatibility differences](docs/upstream-compatibility.md)
and [upgrade instructions](UPGRADING.md).


See [UPGRADING.md](UPGRADING.md) for compatibility and reconciliation instructions.

## [2.0.1] — 2026-10-07

## [2.0.0] — 2026-10-05

- Adopt 74 workflows as repository skills and 49 roles as inheriting TOML profiles,
  retaining professional lifecycle procedures, contracts, gates and templates.
- Add engine-neutral installation/upgrades with integrity hashes, ownership preflight,
  locking, preservation, idempotency and normal-failure rollback.

  linked SHA-256 review receipts and reviewed argv commands.
- Supply optional native hook definitions/JSON handlers without registration, trust,
  permission changes, model selection or fabricated participants.

## Upstream 1.x history

The framework derives from Donchitos' Claude Code Game Studios 1.1.2. Upstream 1.x
introduced the seven-phase lifecycle, configurable rigor/review modes, professional
skills/roles and testing guidance. Its host commands and settings are historical and
are not Codex installation instructions. Original release details remain in Git
history and the [upstream repository](https://github.com/Donchitos/Claude-Code-Game-Studios).
See [source attribution](NOTICE.md).
